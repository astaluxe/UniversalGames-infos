🌳 Cómo empezar una partida

Los primeros minutos son muy importantes.

🪵 Primeros pasos
  1. Consigue madera.
  2. Crea una mesa de crafteo.
  3. Haz un pico de madera.
  4. Consigue piedra.
  5. Crea herramientas de piedra.
  6. Busca comida.
  7. Construye un refugio antes de la noche.
💡 Intenta conseguir una cama cuanto antes para saltarte las primeras noches.

💎 Minerales importantes

🪨 Hierro
Muy importante al principio. Sirve para herramientas, armadura, cubos, escudos y muchos objetos básicos.
💎 Diamante
Necesario para fabricar equipo de diamante y progresar hacia Netherite.
🟢 Esmeralda
Principalmente sirve para comerciar con aldeanos.
🔴 Redstone
Se utiliza para mecanismos, granjas automáticas y construcciones técnicas.

✨ Encantamientos recomendados

⚔️ Espada
Buenos encantamientos incluyen Sharpness, Unbreaking, Mending y Looting.
⛏️ Pico
Fortune es ideal para obtener más minerales. Silk Touch permite recoger ciertos bloques directamente. Mending y Unbreaking ayudan a conservar la herramienta.
🛡️ Armadura
Protection, Unbreaking y Mending son una base muy buena para una armadura de supervivencia.

🔥 Nether

El Nether es necesario para avanzar hacia el End.

🔥 Qué necesitas
Lleva buena armadura, comida, bloques, un escudo y al menos una pieza de oro para reducir problemas con Piglins.
🏰 Nether Fortress
Busca una Nether Fortress para encontrar Blazes. Necesitarás Blaze Rods para fabricar Blaze Powder.

🐉 Llegar al End

👁️ Cómo encontrar el Stronghold
Necesitas Eyes of Ender. Lánzalos y sigue la dirección que indican hasta encontrar el Stronghold.
🐉 Ender Dragon
Destruye primero los End Crystals. Después ataca al dragón cuando tengas oportunidad.
💡 Lleva arco, comida, bloques, agua y una buena armadura.

💡 Consejos rápidos

  • No caves directamente hacia abajo.
  • Lleva siempre comida y bloques.
  • Haz un escudo pronto.
  • Guarda objetos importantes en cofres.
  • Utiliza coordenadas para no perder tu base.
  • Consigue aldeanos para obtener mejores trades.
  • Cuando tengas buen equipo, busca Mending.
